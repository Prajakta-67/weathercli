# Weather CLI 🌦️

A simple command-line weather application built with Python.

## What it does

The program uses the OpenWeather API to retrieve current weather data for a specified location.

### Current features

* Makes an HTTP GET request using Python
* Connects to the OpenWeather API
* Retrieves weather data in JSON format
* Extracts weather information from the API response
* Displays the current temperature

## Technologies Used

* Python
* Requests
* OpenWeather API

## How to Run

1. Clone this repository.
2. Make sure Python is installed.
3. Install the required dependency:

```bash
pip install requests
```

4. Add your OpenWeather API key.
5. Run the program:

```bash
python main.py
```
